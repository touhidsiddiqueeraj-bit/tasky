Welcome to Tasky

A three-column board — To Do · Working On · Done — built for speed. No sign-up needed, your data lives on your device. Every action has a keyboard shortcut.

⌨️ Quick start
Press any key to open the task input. Type and hit Enter to save.
⌨️

Adding Tasks

Press any letter or number to open the floating input. Type your task and hit Enter to save. Press Esc to cancel. Tasks always land in To Do first.

🎙️ Voice input
Hold Space to dictate — release to save. Works in Chrome, Edge & Brave.
🎯

Move & Prioritize

Click a task to select it, then press ← → to move between columns. You can also drag and drop. Press 1 2 3 for High / Medium / Low priority.

💡 Pro tip
On mobile, swipe tasks left/right to move them. Click the priority badge to cycle levels.
☁️

Cloud Sync

Sign in with Google via Tasky ▼ → ☁️ Sign in to sync tasks across all your devices. Works fully offline — changes queue locally and sync when you're back online.

🛡️ Your data
No account needed to start. Sign in only when you want sync. Your tasks stay on-device otherwise.
📋

Workspaces

Keep different projects separate with Workspaces. Switch between them using the pill bar at the top. Each workspace has its own tasks, settings, and optional collaboration.

➕ New workspace
Click ＋ New Workspace in the top bar to get started. The first workspace is always "Personal".
⊞

Power Features

Task Groups let you save reusable templates — start typing a group name and hit Enter to expand the whole set instantly. Collaboration lets you share a board with teammates via a 6-character code from Tasky ▼.

💡 You'll find everything in Tasky ▼
Task Groups, Workspaces, Settings, Sign in — all accessible from the menu in the top-left corner.

Keyboard-first task board · Three columns · Zero friction
The Three Columns

To Do
New tasks land here. Your backlog and upcoming items.
⚡

Active tasks. WIP limit of 3 keeps you focused.
✅

Completed tasks. Clear them anytime with one click.

On mobile, tap the ＋ button in the bottom bar instead.

Hands-Free Task Entry
Tasky uses the Web Speech API for real-time voice dictation. Works in Chrome, Edge, and Brave.
Desktop
hold
Hold the Space bar — the voice overlay appears with three pulsing rings.
speak
Speak your task clearly. The transcript appears in real-time as you talk.
release
Release Space to confirm and save. Press Esc before releasing to cancel.
Mobile
tap
Tap the 🎙️ mic button in the bottom bar to start listening.
speak
Say your task. Tap the mic again or the stop button to confirm.
🌐 Browser support: Requires Chrome, Edge, or Brave. Safari and Firefox do not support the Web Speech API. You'll see an error toast if your browser doesn't support it.
⊞
Task Groups
Save a named set of tasks as a reusable template. Start typing a group name in the input — a suggestion appears. Press Enter to expand all tasks instantly. Find it under Tasky ▼ → Task Groups.
📅
Calendar View
See all tasks with due dates in a monthly or weekly calendar. Drag chips to reschedule. Color-coded by status. Click the 📅 button in the To Do header or set a due date on any task.
🗂️
Workspaces
Separate projects with independent boards. Switch via the pill bar at the top. Tab / Shift+Tab cycle through them. Each workspace can have its own collaboration code.
🔄
Recurring Tasks
Set tasks to repeat daily, weekly, or monthly. When moved to Done, they automatically reappear in To Do on schedule. Manage via Settings → Recurring Tasks.
🔴
Priority System
Three levels: High (red), Medium (amber), Low (green). Set with 1/2/3 on a selected task, or tap the badge on mobile.
📊
CSV Import / Export
Import tasks from any spreadsheet. Columns: Task, Status, Priority, Due Date. Export your board as CSV anytime. Both under Settings.
🔐
Local Encryption
Set a passphrase to encrypt all task data stored in your browser with AES-256-GCM. Zero-knowledge — not even the server can read it. Found in Settings → Local Encryption.
🖼️
Custom Background
Upload any image as a board background. Adjust card opacity with a slider so tasks stay readable. Found in Settings → Background Image.
⚡
WIP Limit
Working On column has a hard limit of 3 tasks. This forces you to finish before starting more — a core Kanban principle. You'll get a toast warning if you try to exceed it.
🔔
Due Date Notifications
Enable browser notifications for tasks nearing their due date. Enable in Settings → Due Date Notifications. Requires Chrome/Edge/Brave and permission grant.
☁️
Cloud Sync
Sign in with Google to sync tasks across all your devices via Firebase Firestore. Works fully offline — changes queue locally and sync when reconnected.
🔢
Task Numbers
Every task gets a permanent number (#1, #2…). Deleted numbers get reused. Jump to any task with Alt+G then type the number, or Alt+1–9 for instant access to the first nine.
👥
Real-Time Team Collaboration
Share a board with teammates using a 6-character code. All changes sync live via Firebase. Requires a Google sign-in.
Setting Up
1
Sign in with Google via Tasky ▼ → ☁️ Sign in.
2
Create a Collaboration via Tasky ▼ → 👥 Create Collaboration. You get a 6-character code.
3
Share the code with teammates. They join via Tasky ▼ → 🔗 Join Collaboration.
4
All members see each other's tasks in real-time on a shared board.
Assigning Tasks
syntax
In the floating input, use: task text to::handle priority::high date::2025-06-15
hint
After typing to::, the assign hint appears in blue below the input.
result
The assigned task shows the assignee handle and a notification badge in the team panel.
Team Panel
icon
A 👥 team panel appears when in a collaboration, showing all members and their task counts.
click
Click a member card to inspect their tasks in a read-only panel.
📅 Calendar + Collab: In the Calendar view, tasks assigned to teammates show their avatar initials on chips, color-coded by status.
01
Use Task Groups as daily templates
Create a group called "Morning Routine" with 5 tasks. Every morning, type "Mor" in the input — the suggestion pops up — press Enter. All 5 tasks are added in one keystroke.
02
WIP limit is a feature, not a bug
The 3-task limit on "Working On" is intentional. If you hit it, finish or move something back before starting more. Fewer active tasks = faster completion.
03
Voice input for long tasks
Hold Space and dictate a full sentence. Tasky transcribes it as the task text. Release to save instantly — no typing needed. Great for capturing ideas quickly on desktop.
04
One board per project with Workspaces
Use separate workspaces for Work, Personal, and Side Projects. Tab through them without lifting your hands from the keyboard. Each workspace is fully independent.
05
Undo with Esc
After deleting or moving a task, a toast appears at the top. Press Esc (or click Undo in the toast) within a few seconds to reverse the action completely.
06
Priority filter dots
The colored dots next to column titles are filters. Click the red dot in To Do to show only High-priority tasks. Click again to clear. Great for end-of-day focus sessions.
07
Offline-first by design
All data lives in localStorage. The app works with zero internet. If you have cloud sync enabled, changes queue locally and push to Firestore when you reconnect — you never lose work.
08
Install as a PWA
Tasky is a Progressive Web App. In Chrome/Edge, click the install icon in the address bar to add it to your home screen or desktop. It launches fullscreen with no browser chrome.
