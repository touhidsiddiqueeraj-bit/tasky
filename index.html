⊞
Task Groups — add a whole workflow in one keystroke Create reusable groups of tasks (e.g. "Sprint Setup", "Morning Routine") from Tasky ▼ → Task Groups. Each group has a column toggle (To Do / Working On) and a list of sub-tasks with priorities. When you start typing in the task input, matching group names appear as suggestions — press ↑↓ to navigate, Enter to expand the whole group onto the board instantly. Duplicate tasks are skipped automatically.
⌨️
Just start typing Press any letter or number key to open the task input. Hit Enter to save, Esc to cancel. Tasks land in To Do automatically.
↔️
Move tasks between columns Click a task to select it, then press ← or → to move it. Or drag and drop anywhere.
🎯
Priority & due dates Select a task then press 123 for High / Medium / Low. Click the priority badge to cycle it. Add a due date from the task edit popover.
🔢
Jump to any task instantly Press Alt+1–9 to select by number, or Alt+G then type any number and Enter.
🎙️
Voice input Hold Space to dictate a task aloud. Release to save. Works in Chrome, Edge & Brave.
↩️
Undo in 3 seconds Deleted or moved a task by accident? An undo toast appears immediately. Del key deletes the selected task.
☁️
Cloud sync (optional) Sign in with Google via Tasky ▼ to sync across devices. Works offline — changes queue and sync when back online. Task Groups are preserved on data reset.
👥
Team Collaboration — assign tasks to teammates in real-time Sign in and go to Tasky ▼ → Create Collaboration to start a team. Share the 6-character code with teammates so they can join. As supervisor you get a Team column — click + Assign on any member card to assign them a task with priority and due date. Their board updates live. Members see assigned tasks appear automatically. Power users can type task to::handle priority::high date::20may directly in the input.

Welcome to Tasky

A three-column task board that stays out of your way. No accounts needed to start — your data lives right on your phone.

What you get
To Do · Working On · Done — drag or tap to move tasks between columns.
＋

Add tasks in one tap

Tap the big ＋ Add Task button at the bottom. Type your task and hit Save — done.

Pro tip
Tap the 🎙️ mic button to dictate a task hands-free. Works in Chrome & Edge.
⊞

Task Groups

Create reusable task templates from Tasky ▼ → Task Groups. Name a group, add tasks, choose To Do or Working On.

Instant expand
Start typing a group name when adding a task — tap the suggestion to add all its tasks to the board at once!
🎯

Tap to edit & prioritise

Tap any task to select it, then change its priority, add a due date, or move it to another column.

Priority colours
🔴 High · 🟡 Medium · 🟢 Low — tap the badge to cycle through them.
↔️

Drag, filter & undo

Long-press a task to drag it between columns. Use the coloured dots in column headers to filter by priority. Hit Undo within 3 seconds if you delete by mistake.

Cloud sync
Sign in with Google from Tasky ▼ to sync across all your devices. Task Groups survive data resets.
👥

Team Collaboration

Sign in and create a Collaboration from Tasky ▼. Share the 6-character code with teammates. As supervisor, you get a live Team column to assign and track tasks.

Assigning tasks
Tap + Assign on a member card — pick priority, due date, and send. Their board updates in real-time automatically.
