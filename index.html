Tasky
Simple three-panel task tracking
⌨️
Just start typing anywhere Tasks auto-add to To Do. Press Enter to save, Esc to cancel
↔️
Drag & drop or use keyboard Click a task to select it, then use ← → keys to move between columns
🎯
Set priority & due dates Click the priority badge to cycle it. Select a task then press 1/2/3 to set High/Medium/Low. Delete key removes it
🔢
Quick-select any task by number Press Alt+1–9 to select that task number instantly. Or press Alt+G then type the number and Enter to jump to any task
🔍
Filter by priority Click the colored dots (🔴🟡🟢) in each column header to show only that priority
↩️
Undo mistakes Deleted or moved a task by accident? An undo button appears for 3 seconds
🎙️
Voice input Hold Space to dictate a task (desktop). Tap the 🎙️ button on mobile. Requires mic permission — works in Chrome, Edge & Brave
☁️
Optional cloud sync Sign in with Google from the menu to sync your tasks across devices. Works offline too — data saves locally and syncs when you're back online
